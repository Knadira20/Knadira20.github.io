# Embun Home Stay Website

Website interaktif 6 halaman untuk Embun Home Stay, Kedah.

## Cara Menjalankan / Muat Naik ke GitHub Pages:

1. Ekstrak fail `embun-homestay-website.zip`.
2. Anda akan melihat fail `index.html` dan `README.md`.
3. Muat naik fail `index.html` ke dalam repositori GitHub anda.
4. Pergi ke **Settings** > **Pages** di repositori GitHub anda.
5. Sediakan **Branch** kepada `main` / `master` dan simpan (Save).
6. Laman web anda sedia diakses menerusi alamat `https://username.github.io/repository-name`.
